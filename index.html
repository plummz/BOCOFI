Bottle Collection & Wi-Fi rewards

A reverse vending machine system for the Philippines: insert plastic bottles or aluminium cans, get coins, a Wi-Fi voucher, or points saved to your account. This repository contains all three surfaces of the system.

Machine kiosk

The touchscreen on the vending machine. All 27 screens from the wireframe site map (1.1 Idle → 7.2 Session ended), including app cash-out code redemption, with a built-in sensor simulator.

Open kiosk →

User app

Mobile-first app for recyclers: dashboard with stacked points, coin balance and Wi-Fi time, a full menu, wallet conversions and cash-out codes, a live Wi-Fi countdown, rewards, machine finder, history, notifications and a leaderboard.

Open user app →

Owner / admin

Dashboard for the machine owner: bin capacity, coin hopper and Wi-Fi status per machine, owner alerts, all transaction types, users, Wi-Fi vouchers, cash-out codes and reward settings.

Try the full loop

  • Open the kiosk and the user app in two tabs (or two devices on the same browser profile). They share one local data store and update each other live.
  • User app demo account: maria@example.com · PIN 1234
  • Admin login: admin / admin123
  • On the kiosk, tap Log in, then in the app choose Link to machine and type the 4-letter code shown on the kiosk.
  • Use the kiosk's sensor simulator (bottom of the insert screen, or the ☰ menu) to "insert" bottles and cans.

No backend is required — everything runs from static files and localStorage. See README.md for the data model and how to connect a real server.
